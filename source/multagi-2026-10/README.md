## 사연 검산 (대본 지시사항 3번)

사연 인물은 실제 주가 흐름을 바탕으로 재구성했다. 영상 화면에 "실제 주가 흐름을 바탕으로 재구성한 사연" 문구를 넣는다. (제목 지시사항 8번)
계산은 달러 주가의 등락률로만 했고 환율 변동은 뺐다. 단위는 만 원이다.

- "-2천만 원"은 장중 저가 기준 -1,954만 원을 반올림한 값이다. 이전 영상도 장중 저점 -1,930만 원을 "-2천만 원"으로 썼다.
- 물타기를 하지 않았을 때 같은 시점 손실: -1,741만 원 → 물타기로 손실이 213만 원 커짐 ("200만 원 넘게")
- 시작 -2.8% → 최종 -24.4%로, 제목 지시사항 4-10의 물타기 기준값(시작 -3% 안팎 → 최종 -20~30%)에 맞는다.

## 지시사항 적용 메모

- 사용자 초안이 없어서 처음부터 작성했다. 그래서 "사용자 문장 그대로" 원칙(대본 지시사항 0번)을 적용할 문장이 없다. 사용자 원문 예시 중 그대로 쓴 문장은 "하지만 그건 달콤한 꿈일 뿐이었습니다.", "물타기 할 돈도 없는데 하필이면 제가 산 다음에 이런 일이 일어나다니요.", "이 세상은 저한테 너무 가혹한 것 같아요."이다.
- 항목 수는 보강 기준(대본 지시사항 0-1-8)으로 문제 분석 4개, 올바른 방법 5개로 했다.
- 사연 비트 ③ "초기 수익과 기대감"은 물타기 주제에 맞게 "초기 작은 손실 → 물타기 → 기대감"으로 바꿨다. 제목이 수익이 아니라 손실(-200만원)에서 시작하기 때문이다.
- 채널명이 없어서 인사는 "안녕하세요."만 썼다. (대본 지시사항 0-1-2)
- 투자 유의 사항 카드는 4가지 요소를 모두 넣었다. (대본 지시사항 0-1-6)
- 50자를 넘는 자막 문장은 없다. 고지 카드 문구는 자막이 아니라 제외했다.
